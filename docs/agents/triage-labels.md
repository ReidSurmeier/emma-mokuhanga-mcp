# Triage labels

Use exactly one of these workflow roles:

- `needs-triage`: the report has not been classified.
- `needs-info`: required evidence or authorship input is missing.
- `ready-for-agent`: scoped technical work can proceed autonomously.
- `ready-for-human`: physical, artistic, rights, or consequential judgment is
  required.
- `wontfix`: the work is intentionally outside this experiment.

Capability labels may be added separately, but must not replace a workflow
role.
